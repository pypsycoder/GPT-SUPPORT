# Cloud.ru / GigaChat 3.5 Ultra — прикидка стоимости

Дата: 2026-09-03. Для решения о переводе прод-контура на Cloud.ru (ROADMAP_AGENT.md Фаза 6).

## Тариф

GigaChat 3.5 Ultra на Cloud.ru Evolution Foundation Models
([cloud.ru/blog](https://cloud.ru/blog/cloud-ru-pervym-otkryl-dostup-k-gigachat-3-5-ultra)):

| | ₽ за 1 млн токенов |
|---|---|
| Вход (prompt) | **96** |
| Выход (completion) | **289** |

**Цена кэшированных токенов (`prompt_tokens_details.cached_tokens`) в документации
не опубликована.** Ниже — три сценария: без скидки / кэш −90 % (типовая практика,
[Habr](https://habr.com/ru/articles/978498/)) / кэш бесплатно. Уточнить у поддержки
Cloud.ru перед переводом.

## Профиль одного сообщения пациента

Из `llm.llm_call_log` (единственный реальный пациент, 159 сообщений за 182 дня
дев-тестирования; ~4.4 LLM-вызова на сообщение — router L2 + safety + agent +
agent_tools + judge + иногда summarizer):

| | токенов на сообщение |
|---|---|
| вход всего | ~10 900 |
| из них кэш-хит на Cloud.ru | ~99 % (в проде замерено 99.7 % на agent-ходах) |
| выход | ~460 |

## Стоимость сообщения

| Сценарий по кэшу | ₽ / сообщение |
|---|---|
| кэш по полной ставке (96 ₽) | **≈ 1.18** |
| кэш −90 % (9.6 ₽) | **≈ 0.29** |
| кэш бесплатно | **≈ 0.19** |

(Выход даёт ~0.13 ₽ из любого сценария — он не кэшируется.)

`safety_classifier` — отдельный вызов на каждое сообщение мимо L0 (~1350 токенов
рубрики, почти весь кэш, 26 на выход) → **≈ 0.01 ₽**, в общей сумме теряется.

## Проекция

Реактивный контур, ₽/месяц:

| Пациентов активно | ~15 сообщений/день | кэш по полной | кэш −90 % |
|---|---|---|---|
| 20 (пилот) | 300 сообщений/день | ~10 600 | ~2 600 |
| 50 | 750/день | ~26 500 | ~6 500 |
| 100 | 1 500/день | ~53 000 | ~13 000 |

Проактивный контур (2 сообщения/пациента/день, полный пайплайн каждое) добавляет
**~13 %** сверху.

## Вывод

Для исследовательского пилота (десятки пациентов) — **единицы–первые десятки
тысяч ₽/месяц**, порядок величины комфортный. Главный рычаг неопределённости —
политика биллинга кэша (разница ×4 между сценариями). До перевода прода:

1. Спросить поддержку Cloud.ru: тарифицируются ли `cached_tokens` и по какой ставке.
2. Запросить повышение RPM/TPM под ожидаемую конкуренцию (базовый лимит ~16
   параллельных на ключ, 429 около 24 — SPRINT1_INVESTIGATIONS.md §1 доп. 2).
3. Держать `llm_call_log` под наблюдением первые недели после перевода —
   `account_id LIKE 'cloudru-%'` + `model` + `precached_tokens` уже разделяют канал.
